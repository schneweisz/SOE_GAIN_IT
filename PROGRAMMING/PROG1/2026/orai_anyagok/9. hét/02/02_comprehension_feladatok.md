# Programozás 1 – Comprehension feladatok

## Feladat 11 – Négyzetek listája
Készíts listát az 1-től 20-ig terjedő számok négyzeteiből comprehensionnel.

## Feladat 12 – Páros számok négyzete
Adott a lista:
```python
szamok = [2, 5, 8, 11, 14]
```
Készíts listát csak a páros számok négyzetéből.

## Feladat 13 – Nagybetűs szavak
Adott a lista:
```python
szavak = ["alma", "körte", "banán"]
```
Készíts nagybetűs listát comprehensionnel.

## Feladat 14 – Hosszabb szavak szűrése
Adott a lista:
```python
szavak = ["alma", "körte", "barack"]
```
Készíts listát az 5 betűnél hosszabb szavakból.

## Feladat 15 – Páros/páratlan szövegek

```python

```

```python
["1 páratlan", "2 páros", "3 páratlan", ...]
```

## Feladat 16 – Szóhosszak
Adott a lista:
```python

```

## Feladat 17 – Dict comprehension
Adott a lista:
```python
szavak = ["alma", "körte", "eper"]
```
Készíts szótárat, ahol a kulcs a szó, az érték pedig az első betű.

## Feladat 18 – Dict szűrés
Adott a szótár:
```python

```
Készíts új szótárat, amelyben csak a 3-nál nagyobb értékek maradnak.

## Feladat 19 – Set comprehension

