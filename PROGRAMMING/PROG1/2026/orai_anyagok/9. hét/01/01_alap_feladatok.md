# Programozás 1 – Alap feladatok

## Feladat 1 – Páros számok kigyűjtése
Adott a lista:
```python
szamok = [3, 8, 11, 14, 20, 21, 24]
```
Készíts új listát, amely csak a páros számokat tartalmazza.

## Feladat 2 – Nevek hossza
Adott a lista:
```python
nevek = ["Anna", "Lajos", "Éva", "Kristóf"]
```
Készíts listát, amely minden név hosszát tartalmazza.

## Feladat 3 – 100-nál nagyobb számok összege
Adott a lista:
```python
szamok = [45, 120, 87, 230, 15, 180]
```
Számold ki a 100-nál nagyobb elemek összegét.

## Feladat 4 – Pozitív számok száma
Adott a lista:
```python
szamok = [-2, 5, 0, 3, -1, 8]
```
Számold meg, hány pozitív szám van benne.

## Feladat 5 – Legkisebb szám keresése
Adott a lista:
```python
szamok = [12, 7, 25, 3, 18]
```
Írd ki a legkisebb számot beépített függvény nélkül.

## Feladat 6 – Hosszú szavak
Adott a lista:
```python
szavak = ["kutya", "macska", "ló", "elefánt"]
```
Írd ki azokat a szavakat, amelyek hossza legalább 5.

## Feladat 7 – Összes karakter száma
Adott a lista:
```python

```
Számold ki, összesen hány karakter van a listában.

## Feladat 8 – Páros indexű elemek
Adott a lista:
```python

```
Gyűjtsd ki a páros indexű elemeket.
