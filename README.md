# SOE_Prog_PY

Soproni Egyetem – Programozás (1 és 2) – gyakorlati anyagok, házi feladatok, zh megoldások és segítő anyagok.

## Felépítés

```
SOE_Prog_PY/
├── PROG1/                  Programozás 1 tárgy anyagai
│   ├── 2025/                  Féléves házi feladatok
│   ├── 2026/                  Órai anyagok, minta zh, zh megoldások
│   └── cheat_sheets/           Python alapok segédanyagai (fájlkezelés, keresés/szűrés, rendezés, statisztika)
│
└── PROG2/                  Programozás 2 tárgy anyagai
    ├── Programozas_2_heti_bontas.pdf   Féléves heti bontás/tematika
    ├── orai_anyagok/                    Órai anyagok alkalomra bontva
    └── cheat_sheets/                    Segédanyagok 
```

## Tartalom

- **Házi feladatok** (`PROG1/2025`): az egyes féléves HF-ek külön mappákban.
- **Zh-k és minta zh-k** (`PROG1/2026`): megoldások és gyakorló feladatok.
- **Órai anyagok** (`PROG1/2026/orai_anyagok`, `PROG2/orai_anyagok`): a gyakorlatokon feldolgozott témák és kódpéldák.
- **Cheat sheet-ek** (`PROG1/cheat_sheets`, `PROG2/cheat_sheets`): gyorsan átnézhető, kommentezett példakódok egy-egy témakörhöz (pl. fájlkezelés, rendezés, matplotlib).
